# دوائي — تذكير الأدوية والتحاليل (Android / Expo)

تطبيق عربي بالكامل (RTL) يعمل محليًا بدون سيرفر، مبني بـ React Native + Expo وموزَّع كـ APK عبر EAS Build.

## البناء والتنزيل (APK)

1. ثبّت Node.js (LTS) ثم: `npm install`
2. سجّل الدخول: `npx eas login`
3. أنشئ معرّف المشروع: `npx eas init` (سيقوم بتحديث `extra.eas.projectId` في app.json تلقائيًا)
4. ابنِ ملف APK: `npx eas build -p android --profile apk`
5. من صفحة البناء في expo.dev نزّل ملف APK وثبّته على الجهاز.

## ملاحظات مهمة

- التشغيل الأول: إذا ظهرت الواجهة بالاتجاه الإنجليزي، أغلق التطبيق وافتحه مرة أخرى (ضبط RTL يحتاج إعادة تحميل).
- أندرويد 13+: اسمح بالإشعارات عند أول فتح.
- لضمان دقة التنبيه: من شاشة "الإعدادات" افتح "التنبيهات والتذكيرات الدقيقة" واتبع خطوات إيقاف تحسين البطارية.
- كل البيانات محفوظة على الجهاز فقط (AsyncStorage).
